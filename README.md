# 岩瀬自治会 防災アプリ

## 概要

「岩瀬自治会 防災アプリ」は、地域住民の防災意識向上と災害への備えを支援するために作成したWebアプリです。

自治会活動で得られた防災知識や地域情報を、スマートフォンやパソコンから簡単に確認できるようにまとめています。

特別なアプリのインストールは不要で、Webブラウザから利用できます。

# 主な機能

## 🌧 水害マイタイムライン

台風や大雨による水害に備え、災害発生前から避難までの行動計画を作成できます。

- 警戒レベルに応じた行動整理
- 避難開始時期の確認
- 家族での防災行動計画作成

---

## 🏠 地震マイタイムライン

地震発生時に取るべき行動を整理できます。

- 発災直後の行動確認
- 避難判断
- 家庭での備えの確認

---

## ✅ 防災チェックリスト

家庭の防災対策状況を確認する機能です。

確認項目：

- 家の安全対策
- 備蓄
- 避難準備
- 地域とのつながり

自分自身の防災力を確認し、不足している備えを見直すことができます。

---

## 🗺 岩瀬防災マップ

地域の防災情報を確認できます。

掲載内容：

- 避難場所
- 防災関連施設
- 地域の防災資器材
- 防災活動に必要な地域情報

---

# 岩瀬防災訓練

自治会で実施する防災訓練情報を掲載しています。

## 📅 次回訓練

次回開催予定や訓練案内を掲載します。

## 🗓 年間計画

年間の防災活動予定を確認できます。

## 📷 活動実績

過去の防災訓練や活動内容を写真とともに記録しています。

---

# 🔗 防災リンク集

日頃の防災や災害時に役立つ情報サイトをまとめています。

掲載内容：

- 岩瀬自治会ホームページ
- 岩瀬防災Instagram
- 松戸市防災情報
- 千葉県防災情報
- 内閣府防災情報
- 気象庁
- 災害情報サイト

# 開発目的

地域防災力を高めるためには、防災知識を「知っている」だけではなく、

- 自分自身で考える
- 家族で共有する
- 地域で活用する

ことが重要です。

本アプリは、自治会活動とデジタル技術を組み合わせ、日常的に防災へ触れる機会を増やすことを目的として作成しました。
